# phx-core
A frontend hypermedia framework for PHP.

## Install from Repository
### Add Repository to composer.json
```bash
"repositories": [
        {
            "type": "vcs",
            "url": "https:\/\/github.com\/andreapeverelli\/phx-core.git"
        },
    ]
```
### Install
```bash
composer require andreapeverelli/phx-core
```

### Usefull commands
#### Do all testings/buildings
```bash
composer prepare
```
#### Run tests + Get test coverage
```bash
composer test
```
#### Code analysis
```bash
composer analyse
```
#### Linting analysis
```bash
composer lint
```
#### Linting fix
```bash
composer fix
```
